
# File Handling in Java

## Project Description
This project demonstrates file handling operations in Java. It reads data from an input file, processes the content, and writes the results to an output file.

## Objectives
- Read data from a text file.
- Count lines, words, and characters.
- Write processed results to an output file.
- Handle file-related exceptions using `IOException`.

## Technologies Used
- Java
- Eclipse Temurin JDK 17
- VS Code

## Features
- Reads content from `input.txt`.
- Calculates the total number of lines, words, and characters.
- Saves the results in `output.txt`.
- Handles missing files and other file-related errors.

## Project Files
- `FileHandling.java` – Main Java program.
- `input.txt` – Input text file.
- `output.txt` – Generated results file.

## How to Run

Compile the program:

powershell
javac FileHandling.java


Run the program:

powershell
java FileHandling


## Sample Output


FILE HANDLING RESULTS
---------------------
Total Lines: 4
Total Words: 27
Total Characters: 168


*Note: The output depends on the content of the input file.*
