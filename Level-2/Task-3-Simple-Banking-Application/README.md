# Task 3: Simple Banking Application

## Internship
Codveda Java Development Internship – Level 2 (Intermediate)

## Description
A simple console-based banking application developed using Java and Object-Oriented Programming (OOP). The application allows users to deposit money, withdraw money, check their account balance, and view account details.

## Features
- Deposit money
- Withdraw money
- Check account balance
- View account details
- Prevent invalid deposits
- Prevent withdrawals exceeding the available balance
- Menu-driven console interface

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Scanner
- VS Code

## Files
- `BankAccount.java` – Handles account information and banking operations.
- `BankingApplication.java` – Main program with the banking menu.

## How to Run
powershell
javac BankAccount.java BankingApplication.java
java BankingApplication
