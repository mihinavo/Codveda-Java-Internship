# Employee Management System

## Project Description
The Employee Management System is a simple Java console-based application developed using Object-Oriented Programming (OOP) concepts.

It allows users to manage employee records using CRUD operations (Create, Read, Update, and Delete). Employee information is stored temporarily in an ArrayList.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## Features
1. **Add Employee** – Add a new employee with ID, name, department, and salary.
2. **View Employees** – Display all employee records.
3. **Update Employee** – Update an existing employee's details.
4. **Delete Employee** – Remove an employee using their ID.
5. **Exit** – Close the application.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the Java files:


javac Employee.java EmployeeManagementSystem.java

4. Run the application:


java EmployeeManagementSystem
