# Number Guessing Game – Java

**Internship:** Codveda Technology – Java Development

**Level:** Level 1 – Basic

**Task:** Task 2 – Simple Number Guessing Game

## Description
A Java console-based game where the computer generates a random number between 1 and 100. The user must guess the number within seven attempts.

## Objectives
- Generate a random number using Java's Random class.
- Accept guesses from the user.
- Provide feedback for high and low guesses.
- Limit the number of attempts.
- Handle invalid inputs.

## Technologies Used
- Java 17
- Visual Studio Code
- Random class
- Scanner class

## How to Run

Compile:

javac NumberGuessingGame.java


Run:

java NumberGuessingGame


## Features
- Random number generation
- Seven attempts per game
- Too high / Too low feedback
- Invalid input handling
- Game Over message
