# Basic Calculator – Java

**Internship:** Codveda Technology – Java Development

**Level:** Level 1 – Basic

**Task:** Task 1 – Basic Calculator

## Description
A simple Java console-based calculator that performs basic arithmetic operations.

## Objectives
- Perform addition, subtraction, multiplication, and division.
- Accept numerical input from users.
- Handle division by zero.
- Use methods to organize arithmetic operations.

## Technologies Used
- Java 17
- Visual Studio Code
- Scanner class

## Operations
1. Addition
2. Subtraction
3. Multiplication
4. Division

## How to Run

Compile:

javac Calculator.java


Run:

java Calculator


## Sample Output

Enter first number: 20
Enter second number: 10
Enter your choice (1-4): 1
Result: 30.0

Successfully developed a basic calculator using Java. This project provided practical experience with methods, user input, switch statements, and exception handling.
