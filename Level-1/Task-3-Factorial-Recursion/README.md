# Factorial Calculation using Recursion – Java

**Internship:** Codveda Technology – Java Development

**Level:** Level 1 – Basic

**Task:** Task 3 – Factorial Calculation using Recursion

## Description
A Java console application that calculates the factorial of a number using a recursive method.

## Objectives
- Implement a recursive factorial method.
- Handle factorial of zero.
- Handle negative numbers.
- Prevent overflow for values greater than 20.

## Technologies Used
- Java 17
- Visual Studio Code
- Scanner class
- Recursion

## How to Run

Compile:

javac Factorial.java


Run:

java Factorial


## Sample Output

Enter a number: 5
Factorial of 5 is: 120

Successfully implemented a factorial calculator using recursion in Java. This project improved my understanding of recursive methods, base cases, and input validation.
