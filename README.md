## 🚀 How to Run

1. Install the Java Development Kit (JDK).
2. Clone this repository:

bash
git clone https://github.com/mihinavo/Codveda-Java-Internship.git


3. Open the required project folder in VS Code or another Java IDE.
4. Compile and run the Java files according to the instructions in each project's README.

**Note:** The Library Management System requires MySQL and the MySQL Connector/J library. Configure the `DB_PASSWORD` environment variable before running the application.
